# Python Interview Prep

Topic-by-topic. Each topic has three parts:

1. **Notes** — `NN-topic.md` — short theory, one line per idea, with a self-check.
2. **Exercises** — `exercises/NN-topic.py` — fill in the `TODO`s, run the file; asserts check you.
3. **Interview questions** — kept at the bottom of the notes file.

Run an exercise file:  `python3 python/exercises/01-lists-and-tuples.py`
Green = all asserts passed.
